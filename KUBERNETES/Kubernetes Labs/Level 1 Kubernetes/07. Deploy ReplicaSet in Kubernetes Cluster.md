# Deploy ReplicaSet in Kubernetes Cluster

The Nautilus DevOps team is gearing up to deploy applications on a Kubernetes cluster for migration purposes. A team member has been tasked with creating a ReplicaSet outlined below:  
1. Create a ReplicaSet using `httpd` image with `latest` tag (ensure to specify as `httpd:latest`) and name it `httpd-replicaset`.     
2. Apply labels: `app` as `httpd_app`, `type` as `front-end`.      
3. Name the container `httpd-container`. Ensure the replica count is `4`.  
`Note:` The `kubectl` utility on the `jump-host` has been configured to work with the Kubernetes cluster.

---


```bash

thor@jump-host ~$ kubectl create -f replicaset.yml 
replicaset.apps/httpd-replicaset created
thor@jump-host ~$ kubectl get replicasets
NAME               DESIRED   CURRENT   READY   AGE
httpd-replicaset   4         4         4       6s
thor@jump-host ~$ kubectl get pods
NAME                     READY   STATUS    RESTARTS   AGE
httpd-replicaset-7hqnw   1/1     Running   0          11s
httpd-replicaset-m8lgz   1/1     Running   0          11s
httpd-replicaset-x487c   1/1     Running   0          11s
httpd-replicaset-zn4fm   1/1     Running   0          11s
thor@jump-host ~$ cat replicaset.yml 
apiVersion: apps/v1
kind: ReplicaSet
metadata:
  name: httpd-replicaset
  labels:
    app: httpd_app
    type: front-end
spec:
  replicas: 4
  selector:
    matchLabels:
      type: front-end
  template:
    metadata:
      name: myapp-pod
      labels:
        app: myapp
        type: front-end
    spec:
      containers:
        - name: httpd-container
          image: httpd:latest
```
